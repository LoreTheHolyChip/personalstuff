# KDE Connect Integration — source status

> **Work in progress — source code archived for review, not an installable release.**
> These source files have **not** been compiled or tested from this repository.
> Both modules require additional headers. Do not install the incomplete source
> into Windhawk expecting it to work.

## Modules

- [KDE Connect Integration](kde-connect-integration.wh.cpp) — version 0.6.0, loaded into `explorer.exe`, taskbar panel.
- [KDE Connect Battery Module](kde-connect-battery-module-windows.wh.cpp) — version 0.1.0, loaded into `kdeconnectd.exe`; reads battery packets and saves state to the user's Registry.

For battery display, both modules are needed, plus their support headers.
The adapter explicitly checks for Qt 6.11.1 x64; other builds are refused.
Qt ABI hooks and Explorer UI modifications require testing before use.

## Missing required headers

Please provide the **original** headers, not autogenerated substitutes:

- `kde-integration-json.hpp` — JSON parser used by the battery adapter
- `kde-integration-devices.hpp` — device selection/name preferences
- `kde-integration-dbus.hpp` — KDE connection and notifications handling
- `kde-integration-panel.hpp` — notification/popup rendering
- `kde-integration-taskbar.hpp` — native taskbar integration
- `kde-integration-settings-panel.hpp` — mod settings UI

Until these files are available, compilation cannot be verified.
Any other dependencies those headers have must be checked too.

## Screenshot migration

The main README currently embeds GitHub user-attachment image URLs.
To keep screenshots **inside this repository**, manually upload the
original PNG/JPEG/GIF files into a new `screenshots/` directory and
change the links to relative paths such as
`screenshots/kde-taskbar.png` and `screenshots/kde-panel.png`.
Do not delete existing attachments until the new links work.
